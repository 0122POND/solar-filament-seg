Metadata of the Kaggle Dataset that hosts the trained weights of NLv + NNR (configs/nlv.yaml):
  weights/  -> deepernet/solar-filament-nlv-weights  (files: weights/MANIFEST_nlv.tsv, checksums: weights/MD5SUMS.txt)
To create it: put the files at their manifest paths next to dataset-metadata.json and run
  kaggle datasets create -p <folder> --dir-mode zip
